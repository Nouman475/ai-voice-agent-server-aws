## Project Overview

The **Yeastar AI Voice Assistant** is a Node.js application that integrates AI-powered voice assistance with Yeastar PBX systems. It provides real-time voice processing capabilities using Google's Gemini AI, speech-to-text (STT), and text-to-speech (TTS) services.

### Key Features
- **Real-time Voice Processing**: WebSocket-based audio streaming
- **AI-Powered Responses**: Google Gemini Pro integration
- **Multi-language Support**: Urdu and English TTS/STT
- **PBX Integration**: Direct integration with Yeastar PBX systems
- **IVR Management**: Dynamic IVR prompt generation and management
- **Session Management**: Call session tracking and management
- **Audio Processing**: Whisper.cpp for speech recognition
- **SFTP Integration**: Audio file upload to PBX systems

### Technology Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **AI Service**: Google Gemini Pro
- **Speech Recognition**: Whisper.cpp
- **Text-to-Speech**: Google TTS (gTTS)
- **WebSocket**: ws library
- **File Transfer**: SSH2 SFTP Client
- **Audio Processing**: Buffer-based audio handling

## Architecture

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Yeastar PBX   │◄──►│  Voice Assistant │◄──►│   Google AI     │
│                 │    │                 │    │   Services      │
│ • Call Routing  │    │ • WebSocket     │    │ • Gemini Pro    │
│ • IVR System    │    │ • Audio Proc.   │    │ • TTS/STT       │
│ • SFTP Server   │    │ • Session Mgmt  │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### Data Flow
1. **Incoming Call** → Yeastar PBX → Webhook → Voice Assistant
2. **Audio Stream** → WebSocket → STT → AI Processing → TTS → Response
3. **IVR Management** → Dynamic prompt generation → SFTP upload → PBX update

## Services

### 1. Gemini Service (`src/services/gemini.service.js`)
**Purpose**: Interface with Google Gemini AI for text generation

**Key Methods**:
- `generateReply(sessionId, text)`: Generate AI response to user input

**Features**:
- Fallback responses for API failures
- Configurable token limits and temperature
- Multi-language support
- Professional phone assistant persona

**Configuration**:
```javascript
const result = await model.generateContent({
  contents: [{ role: "user", parts: [{ text: prompt }] }],
  generationConfig: {
    maxOutputTokens: Number(process.env.MAX_OUTPUT_TOKENS) || 100,
    temperature: 0.7,
    topP: 0.9,
  },
});
```

### 2. Call Session Service (`src/services/call-session.service.js`)
**Purpose**: Manage call sessions and their lifecycle

**Key Methods**:
- `createSession()`: Create new session with UUID
- `getSession(id)`: Retrieve session by ID
- `endSession(id)`: Terminate session
- `mapCallToSession(callId, sessionId)`: Map Yeastar call ID to session
- `getSessionByCallId(callId)`: Get session by Yeastar call ID

**Data Structure**:
```javascript
const session = {
  id: "uuid-string",
  turns: 0,
  createdAt: Date.now()
};
```

### 3. WebSocket Service (`src/services/websocket.service.js`)
**Purpose**: Handle real-time audio communication with Yeastar PBX

**Key Features**:
- Real-time audio streaming
- Connection management
- Message type handling
- Audio buffer management
- Automatic cleanup

**Supported Message Types**:
- `call_start/start_call/call_begin`: Initialize call
- `audio_data/audio/voice_data`: Process audio data
- `call_end/end_call/call_hangup`: Terminate call
- `ping`: Health check

**Audio Processing Flow**:
1. Receive base64 encoded audio chunks
2. Accumulate audio in buffer
3. Process when minimum size reached (3 seconds)
4. STT → AI → TTS → Response

### 4. Speech-to-Text Service (`src/services/stt.service.js`)
**Purpose**: Convert audio to text using Whisper.cpp

**Key Methods**:
- `transcribeAudio(audioBuffer)`: Convert audio buffer to text

**Features**:
- Whisper.cpp integration
- Temporary file management
- Configurable language detection
- Fallback mock responses

**Process**:
1. Write audio buffer to temporary file
2. Execute Whisper binary with model
3. Parse transcript from output
4. Clean up temporary files

### 5. Text-to-Speech Service (`src/services/tts.service.js`)
**Purpose**: Convert text to speech using Google TTS

**Key Methods**:
- `synthesizeSpeech(text, language)`: Generate audio from text

**Features**:
- Multi-language support (Urdu, English)
- Temporary file management
- Buffer-based audio handling
- Error handling with fallbacks

### 6. IVR Manager Service (`src/services/ivr-manager.service.js`)
**Purpose**: Manage Interactive Voice Response system

**Key Methods**:
- `processUserInput(sessionId, userInput, callId)`: Process user interactions
- `getNextIVR()`: Get next available IVR number

**Features**:
- Dynamic IVR assignment
- AI response generation
- Audio file generation
- Special handling for extension 208

### 7. Yeastar API Service (`src/services/yeastar-api.service.js`)
**Purpose**: Interface with Yeastar PBX API

**Key Methods**:
- `login()`: Authenticate with Yeastar API
- `getToken()`: Get/refresh authentication token
- `transferCallToIVR(callId, ivrNumber)`: Transfer call to IVR
- `playAudioToCall(callId, audioFilename)`: Play audio during call
- `updateIVRPrompt(ivrNumber, promptFilename)`: Update IVR prompts

**Authentication**:
- Token-based authentication
- Automatic token refresh
- Session management

### 8. Audio Upload Service (`src/services/audio-upload.service.js`)
**Purpose**: Upload audio files to Yeastar PBX via SFTP

**Key Methods**:
- `uploadAudioToYeastar(localFilePath, remoteFilename)`: Upload audio file

**Features**:
- SFTP connection management
- Remote path configuration
- Error handling and cleanup

### 9. Quota Manager Service (`src/services/quota-manager.service.js`)
**Purpose**: Manage API request quotas and rate limiting

**Key Methods**:
- `canMakeRequest(apiKey)`: Check if request is allowed
- `recordRequest(apiKey)`: Record API request
- `getRemainingRequests(apiKey)`: Get remaining quota
- `getWaitTime()`: Get wait time if quota exceeded

**Configuration**:
- 15 requests per minute limit
- 1-minute reset interval
- Per-API-key tracking

## WebSocket Implementation

### Connection Flow
1. **Client Connection**: Yeastar PBX connects to WebSocket server
2. **Authentication**: Connection validation and logging
3. **Message Handling**: Process different message types
4. **Audio Processing**: Real-time audio stream processing
5. **Response Generation**: AI-powered response generation
6. **Cleanup**: Connection and resource cleanup

### Message Protocol
```javascript
// Call Start
{
  "type": "call_start",
  "callId": "unique-call-id",
  "from": "caller-number",
  "to": "called-number"
}

// Audio Data
{
  "type": "audio_data",
  "callId": "unique-call-id",
  "audio": "base64-encoded-audio"
}

// Audio Response
{
  "type": "audio_response",
  "callId": "unique-call-id",
  "audio": "base64-encoded-response",
  "timestamp": "2025-01-24T..."
}

// Call End
{
  "type": "call_end",
  "callId": "unique-call-id"
}
```

### Audio Processing Pipeline
1. **Receive**: Base64 encoded audio chunks
2. **Buffer**: Accumulate audio data
3. **Threshold**: Process when minimum size reached
4. **STT**: Convert speech to text
5. **AI**: Generate intelligent response
6. **TTS**: Convert response to speech
7. **Send**: Return audio to caller

## Setup and Installation

### Prerequisites
- Node.js 16+ 
- npm or yarn
- Yeastar PBX system
- Google Cloud API credentials
- Whisper.cpp binary (optional)

### Installation Steps
1. **Clone Repository**:
   ```bash
   git clone <repository-url>
   cd voice-assistant-yeastar
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Environment Setup**:
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. **Download Models**:
   ```bash
   npm run setup
   ```

5. **Start Application**:
   ```bash
   # Development
   npm run dev
   ```
